Registro Soci ASD — Gestionale per associazioni sportive dilettantistiche
Un gestionale completo per la tenuta del registro soci, pensato per ASD e SSD (associazioni e società sportive dilettantistiche), realizzato come foglio di calcolo LibreOffice Calc con macro integrate — nessuna installazione di software aggiuntivo, nessun database esterno, nessun collegamento a internet richiesto per l'uso quotidiano.
Cos'è
Il gestionale funziona interamente all'interno di un unico file (.ods) apribile con LibreOffice Calc (gratuito, disponibile per Windows, macOS e Linux). Tiene traccia dell'anagrafica dei soci, delle tessere associative, delle scadenze dei documenti obbligatori e produce in autonomia i backup dei dati.
Funzionalità principali
    • Gestione anagrafica soci: 
inserimento, modifica, ricerca e cancellazione delle schede socio, con rinnovo automatico da un anno sociale al successivo.
    • Gestione tessere: 
registrazione degli acquisti di tessere per anno accademico, con conteggio automatico di quelle utilizzate e residue.
    • Scadenze documenti: 
calcolo automatico delle scadenze di certificato medico, Safe Guarding e tessera, con avviso all'apertura del file e contatori sempre visibili di documenti da consegnare, in scadenza (entro 30 giorni) e scaduti.
    • Sicurezza dei dati: 
protezione dei fogli con password, backup automatici a ogni salvataggio con rotazione (le copie più vecchie vengono eliminate automaticamente), avviso se il file non è protetto da password di apertura.
    • Aggiornamento automatico: 
il gestionale può verificare e installare da solo le nuove versioni pubblicate, controllando che il file scaricato sia integro tramite un codice di controllo (checksum) prima di sostituire quello in uso; il file precedente resta comunque conservato nella cartella di backup.
    • Esportazione: 
esportazione dell'elenco soci nel formato richiesto per la trasmissione all'ente/federazione di riferimento.
Requisiti
    • LibreOffice (versione recente) su Windows, macOS o Linux.
    • Nessun altro software richiesto.

Trattamento dei dati personali
Il gestionale tratta dati personali dei soci dell'associazione, ed eventualmente di minorenni. La responsabilità del trattamento (titolarità ai sensi del Regolamento UE 2016/679 - GDPR) resta in capo all'associazione che lo utilizza, che dovrà adottare misure adeguate per la protezione del file (password di apertura, backup sicuri, accesso riservato a chi ne ha necessità).
